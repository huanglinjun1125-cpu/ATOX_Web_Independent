# ATOX 网站品牌系统

全站采用同一套基础变量与组件语言。黑色提供主体背景，暖白承担阅读层级，珊瑚红只用于重要行动、图形节点与必要状态强调。源项目的紫色和荧光绿视觉已统一。

| 变量 | 值 | 用途 |
| --- | --- | --- |
| --bg | #090a0a | 主背景 |
| --panel | #111313 | 功能面板 |
| --text | #f1f0e9 | 主要文字 |
| --muted | #a4a8a5 | 次级文字 |
| --line | #333635 | 分区边界 |
| --accent | #ff665c | 主行动和线性图形节点 |

采用系统无衬线字体，信息标记辅以等宽字体，不依赖远程字体。宽屏统一 1280px 内容区；移动端采用 22px 边距，网格由四列降为两列或一列。长页通过主次字号、对齐与留白建立层级，避免渐变色块和密集装饰。既有成功、错误等业务状态保留语义可辨性。

主视觉和赛道图标是源码中的原创 SVG，支持缩放且无需图片网络请求。共享导航具有当前页提示、手机菜单与键盘关闭；议程使用可键盘导航的标签页；弹窗使用原生 dialog，关闭后恢复触发按钮焦点；FAQ 使用原生 details。减少动态效果偏好受到尊重。

活动与主页复用同一套视觉构成，但内容保持各自职责。马来西亚活动采用策划案英语优先的默认内容；中文访问者可切换。未确认事项以邻近文案呈现，不用虚构的嘉宾肖像、赞助商标识或奖金丰富版式。
