# M003 1.1.0 · 模拟购票与我的订单验收

日期：2026-10-09。范围为临时菜单入口、购票内部导航及本人历史订单列表；无真实收款、退款、出票或核销。

## 功能与权限

- 展开右上角菜单，在项目之后显示“购票（模拟）／Tickets (Demo)”，点击进入选票并收起。仅 development 且 ENABLE_TICKETING_PREVIEW=true 可见。
- 选票、结算、订单页提供购买门票／我的订单切换。未登录访问订单页通过认证 next 返回原页，含分页条件；会话失效后刷新返回登录。
- GET /api/preview/ticketing/demo/orders?page=1 按服务端当前账号及演示活动查询，每页 10 条，创建时间倒序、同值 ID 倒序。先同步本人本活动 pending 订单，不调用全站维护。
- 历史活动名、票种、金额和时区来自订单快照。摘要不含问卷、邮箱、幂等键或渠道内部记录；响应 no-store。非法／重复页码、额外 userId 等参数返回 400。
- 列表包含待支付、已支付、已关闭、确认中、待对账；未知结果不允许重复付款，迟到成功不宣称购票成功。查看订单和继续支付复用现有 checkout?orderId 页面。
- 服务测试覆盖账号及活动隔离、12 条历史记录分页、配置修改不覆盖快照、仅刷新本账号过期订单、未知状态保留预留、支付成功与迟到收款不被重复查询破坏。

首页和项目展区回归的报名入口断言已匹配当前活动大厅快捷入口，认证返回路径断言保留。桌面及手机截图已检查；手机订单内容加载后无横向溢出，长订单号、状态、分页可见。
