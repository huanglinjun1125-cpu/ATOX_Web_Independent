# M003 1.2.0 · 统一购票界面与精简结算

日期：2026-10-09。范围为三页主站样式接入、自动报价、合并下单与发起模拟支付、浏览器恢复及确认交互。无真实扣款。

## 交付行为

- 选票、结算、本人订单共享 HACKATHON 顶部导航、账户／语言／菜单及简洁页脚；深色卡片、紫色强调、荧光绿主按钮。购买门票／我的订单仍互通，结算归属购买门票。
- 资料有效后 500 毫秒防抖自动报价；修改立即使旧报价失效。旧响应不能覆盖新输入，失败可重试。报价不创建订单或预留库存。
- 一次确认依次创建订单并启动模拟支付。先同步写入订单地址再付款，避免立即刷新返回资料页；支付结果仍由服务端确认。
- 双击只产生一次下单及支付请求。未知下单保存原请求和幂等键，刷新后先查询本人订单再恢复；恢复不会自动付款。明确失败且内容不变的重试保留原键。
- 支付响应丢失先查单，未知结果禁止重复支付；原预留、关单、已支付、迟到收款及待对账规则延续。
- 新报价需再次确认，政策变化须重新勾选同意。已有待处理订单提供继续入口，不自动进入付款。
- 改票使用原生 dialog，支持 Esc、焦点约束和恢复；模拟面板可折叠，启动支付后展开。中英文及 320／390／768／1280px 布局已检查。

## 接口、兼容与留存

原 HTTP 接口及公开 DTO 不变，顺序复用 quote／orders／payments；浏览器状态集中在 use-checkout.ts。无新增表、迁移、业务环境变量或依赖；旧用户、会话、订单及快照保留。

与 M003 1.1.0 源码包逐项比对，12 个既有迁移／财务相关文件哈希一致，包含迁移历史、schema.ts 与 ticketing/service.ts；未重置本地数据库。
