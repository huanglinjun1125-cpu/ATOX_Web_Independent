## 覆盖和观察

- 活动时间起止毫秒边界、报名与活动时间独立、跨年时区年份、所有阶段排序及同值 ID 排序；过滤不修改输入数组。
- 双语名称／主题搜索、首尾空白及大小写、年份与阶段交集、计数／空状态／重置、推荐在筛选与结束后隐藏；重复推荐和危险链接配置拒绝。
- 卡片站内详情链接、HTTPS 外链标识／新标签／noopener、无目标禁用、缺图占位、长标题和 HTML 文本转义；未发布／未知活动拒绝解析。
- 同账号并发报名两场活动；独立草稿、正式提交、修订号、两个活动分别受理及重提结果保持独立，旧 demo 无参调用继续有效。
- 其他活动文件 ID 不能读取或引用，受理人员不能跨活动处理同一材料 ID；孤儿清理保留所有活动的有效正式／草稿引用。
- 浏览器从卡片进入正确详情和报名，登录返回选定活动；返回展板遵守未保存离开确认。刷新恢复草稿、筛选和语言，键盘可以由搜索切至年份。
- 浏览器断言桌面 3 列、900px 平板 2 列、390px 手机 1 列、无横向溢出；已检查桌面及手机全页截图，封面完整显示、文本及控件布局正常。
- M001 登录、持久会话、退出、Origin 校验；M002 完整提交／受理、冲突保留输入；M003 选票、问卷、模拟失败／未知恢复、迟到收款及禁用边界回归通过。

首轮新增浏览器用例曾等待含“草稿”的任意状态，误把未保存提示当作保存完成，导致测试提前导航并中止请求。已改为等待明确“草稿已保存”成功提示，定向两项及最终全套 11 项通过。另修正空材料的默认赛道取当前活动配置，避免未来不同赛道时仍使用 demo 默认值。
