- 手机菜单 Enter 打开、Tab 访问链接、Esc 关闭并恢复按钮焦点；点击锚点后收起，aria-expanded 与实际状态一致。
- 中英文首页及占位页，刷新保留语言和锚点；切换语言仍保留当前阅读章节。中英文段落高度不同，应比较章节在视口中的位置，不能要求绝对 scrollY 数值不变。
- 320px、390px 手机与 768px 平板无横向溢出；已检查英文手机版首页和中文手机项目占位截图。
- 减少动态效果模式下 SVG 动画名称为 none、html scroll-behavior 为 auto；正文无需动画呈现。
- 禁用 JavaScript 时，服务端首页标题、组织介绍、三项主办内容及关键项目入口仍可阅读／导航。
- 首页组织描述及 metadata 使用本站示例内容，无参考站品牌、虚构合作方、联系、政策、社交或备案链接。
