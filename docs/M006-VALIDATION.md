## 项目功能

- 12 项原创双语演示数据，第一页 9 项、第二页 3 项；排序覆盖相同时间按 ID 的确定性顺序。
- 中英文名称、简介、创作者及全部标签搜索，首尾空格／大小写、分类／活动交集、独立项目、未知条件及无匹配结果验证通过。
- URL 分享／刷新／前进后退恢复；非法页码归一、超出页码返回空页并可回第一页；页面结果与 API 一致。
- 网络错误显示重试，旧搜索请求取消后不会覆盖后续结果。
- 弹层 Enter 打开、Tab／Shift+Tab 边界循环、Esc／关闭按钮／遮罩关闭，恢复触发卡片焦点与原滚动位置；分类及页码保留。
- 弹层活动链接进入正确活动，再进入原 M002 报名并保留登录返回目标。
- 320／390／768px 布局无横向溢出；桌面三列、平板两列、手机单列。双语刷新保持，缺封面／图片加载失败使用占位；英文较长简介卡片截断、预览完整显示。
- 减少动态效果时卡片过渡关闭。桌面整页、手机英文整页及预览截图已复核。
- 首页导航、首屏、入口区与页脚的项目链接均进入新展区；手机菜单和无 JavaScript 的首页项目跳转仍通过。
- 登录后项目页显示账户入口。投稿说明页公开可访问，双语、返回展区和探索活动链接可用，无资料输入或假提交表单。
