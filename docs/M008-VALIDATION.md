# M008 1.0.0 · 管理员权限与官方后台入口验收

完成日期：2026-10-10（Asia/Shanghai）。本期只交付后台入口、两类角色、管理员账号管理和权限审计，不接入材料审核或内容发布。

## 实现与权限

- `/admin` 供有效超级／运营管理员使用；`/admin/administrators` 与 `/admin/audit` 仅超级管理员。每个页面和接口分别检查身份与当前数据库角色，不以菜单或 Cookie 角色代替权限。
- 一次性 CLI 绑定已验证账号，来源记录本机执行账号；无公开 bootstrap API，不代建用户。同目标重跑不恢复权限，不同目标拒绝。
- 授权、角色／启用状态变更、修订号和审计同事务提交；排队后重新检查操作者权限。禁止自停用、自降级，交叉超级管理员并发操作不能清空有效超级权限。
- 双语后台、分页、手机导航、确认弹窗、409 输入保留、未知响应先核实记录；权限表单不持久化到浏览器存储。
