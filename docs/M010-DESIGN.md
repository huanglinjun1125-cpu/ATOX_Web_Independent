# M010 活动结构化发布

版本目标 1.0.0。职责为活动草稿、管理员预览、发布与下架；使用共享 content-management 发布核但独立于 M011 首页和 M009 审核。

双语深色 AdminShell：列表新建稳定 ID、编辑结构化字段、保存反馈、live 摘要及只读变更历史。字段包括双语名称／主题／简介／主办／地点，时区、实际起止／报名起止／提交起止六个偏移 ISO 时间，赛道标识及双语名、按行双语规则、推荐／演示标记；封面限三张原创 SVG。ID 不可改，系统文件限制及组队配置保留，不提供任意 JSON 或上传。

草稿独立于 live，保存前不能预览／发布，预览新标签仅管理员可读。发布使用保存版本并复查修订、推荐和赛道引用。下架公开页面及参赛 API 404，旧报名、材料、队伍和审核历史不删；管理员材料详情及独立附件仍能审阅。运行配置必须由数据库发布源解析，写事务再次核验，不能依赖静态兼容入口。

验收覆盖权限／Origin、草稿私密、预览隔离、发布时间与参赛窗口一致、推荐冲突、引用赛道保护、冲突保留输入、下架公众 404及数据延续、跨活动隔离、双语和手机、业务审计。现 88 服务通过，其他最终结果待统筹记录。
