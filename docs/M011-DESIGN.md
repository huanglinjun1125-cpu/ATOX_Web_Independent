# M011 官网结构化内容管理

版本目标 1.0.0。职责为现有首页双语内容草稿、预览、发布和恢复基线，共用发布核但不接管活动／材料业务。

`/admin/content/homepage` 以人类字段标签编辑首屏、组织介绍、主办方向、探索入口、页脚文案和双语 metadata；主办方向固定三项，每项双语标题／副标题／正文。保留现有布局和共享导航，不提供拖拽布局、任意代码或假上传。

草稿保存不影响首页；先保存再预览／发布。预览仅有效管理员可读，发布／下架显式确认。下架恢复原默认静态演示首页，不让首页成为 404，也不公开未保存内容。metadata 虽存双语，默认 HTML 语言接入按现有站点实现，不宣称服务器能读取 localStorage。

修订冲突或不确定网络结果保留输入并锁写，明确重新读取后核对，离开未保存提醒；live 摘要、操作者／时间及前后审计可审阅。内容校验拒绝非法双语字段、超长文本及控制字符；本轮不提供任意链接或代码编辑，正文由 React 转义。

验收覆盖权限、草稿不影响公众、预览私密、发布版本一致、下架基线恢复、409保留输入、双语手机无溢出、审计及原导航／登录回归。88服务已通过，其他验收及归档由统筹记录，不承诺生产上线。
